# Сила (Ультимативная способность)

Ультимативная способность «Сила» (Force Ultimate) — самая мощная способность джедая, служащая «тревожной кнопкой» для мгновенного очищения пространства от врагов, уничтожения всех летящих снарядов и нейтрализации Космического Червя.

---

## 1. Концепция и Смысл ультимативной способности

Разработка механики Силы решает ключевые геймдизайнерские задачи:
*   **Вознаграждение за исследование:** Чтобы активировать ульту, игроку необходимо собирать редкие кристаллы Силы, разбросанные по уровню. Это мотивирует исследовать карту и рисковать, сближаясь со штурмовиками.
*   **Экстренное спасение (Panic Button):** В ситуациях, когда экран перегружен летящими пулями или к игроку вплотную подошел Космический Червь, ульта мгновенно очищает сцену, давая игроку тактическую передышку.
*   **Тактический выбор:** Накопленный ресурс (3 кристалла) можно потратить на мгновенное уничтожение скопления штурмовиков ради зачистки уровня (и получения Медного Ключа), либо приберечь его для защиты от внезапного нападения Червя.

---

## 2. Визуальное оформление и Аудио

*   **Расширяющаяся волна:** При активации Силы вокруг джедая рождается неоновый расширяющийся круг `ForceEffect.prefab`. Он стремительно увеличивается в размерах, постепенно растворяясь (эффект затухания альфа-канала).
*   **Искры Силы:** В момент запуска префаб `forceSparksPrefab` генерирует яркую вспышку и разлет пиксельных частиц.
*   **Световые эффекты штурмовиков:** Уничтожаемые волной штурмовики мгновенно взрываются с помощью `EnemyDeathEffect.prefab`.
*   **Реакция червя:** При активации Силы находящийся на сцене Космический Червь окрашивается в тревожный красный цвет и стремительно улетает за пределы экрана.

---

## 3. Техническая реализация (Код)

Активация Силы разделена на три этапа: проверку условий в `GameManager.cs`, физический расчет зоны поражения в `JediController.cs` и визуализацию волны в `ForceEffect.cs`.

### 3.1. Проверка условий и списание ресурса (`GameManager.cs`)
При нажатии игроком клавиши `Space` контроллер джедая обращается к синглтону `GameManager` для проверки возможности активации:

```csharp
public bool TryUseUltimate()
{
    if (crystals >= 3)
    {
        crystals = 0; // Списываем кристаллы
        if (UIManager.Instance != null) 
            UIManager.Instance.UpdateCrystals(crystals); // Обнуляем HUD
        
        // Вызываем глобальное статическое событие (оповещает Червя о необходимости бегства)
        if (OnUltimateUsed != null) OnUltimateUsed(); 
        
        return true;
    }
    return false;
}
```

### 3.2. Расчет зоны поражения и расщепление снарядов (`JediController.cs`)
Если `TryUseUltimate()` возвращает `true`, запускается метод `UseForce()` в контроллере джедая:

1.  **Спавн визуального эффекта:** В точке нахождения игрока создается объект волны Силы:
    ```csharp
    if (forceSparksPrefab != null) Instantiate(forceSparksPrefab, transform.position, Quaternion.identity);
    ```
2.  **Определение объектов в радиусе поражения:**
    С помощью метода `Physics2D.OverlapCircleAll` создается виртуальная сфера с радиусом `ultimateRadius = 5f`, считывающая все попавшие в нее коллайдеры:
    ```csharp
    Collider2D[] hitObjects = Physics2D.OverlapCircleAll(transform.position, ultimateRadius);
    ```
3.  **Применение эффектов к объектам:**
    *   Если объект — враг (`Enemy`) или червь (`Worm`), на него отправляется запрос на получение урона:
        ```csharp
        hit.SendMessage("TakeDamage", SendMessageOptions.DontRequireReceiver);
        ```
    *   Если в радиусе ульты оказываются летящие пули штурмовиков (`BlasterBolt`), они **мгновенно уничтожаются (расщепляются)**, предотвращая получение урона джедаем:
        ```csharp
        else if (hit.GetComponent<BlasterBolt>() != null) 
        {
            Destroy(hit.gameObject);
        }
        ```

### 3.3. Расширение волны Силы (`ForceEffect.cs`)
Визуальный эффект волны плавно расширяется и растворяется в воздухе за счет изменения масштаба и альфа-канала спрайта.

*   В методе `Update` масштаб объекта непрерывно увеличивается со скоростью `expandSpeed = 15f`:
    ```csharp
    transform.localScale += Vector3.one * expandSpeed * Time.deltaTime;
    ```
*   Прозрачность спрайта `SpriteRenderer` затухает пропорционально скорости расширения:
    ```csharp
    Color c = sr.color;
    c.a -= (expandSpeed / maxScale) * Time.deltaTime; // maxScale = 10f
    sr.color = c;
    ```
*   Как только волна достигает максимального масштаба (`maxScale`) или полностью растворяется (`c.a <= 0`), объект волны уничтожается:
    ```csharp
    if (transform.localScale.x >= maxScale || c.a <= 0)
    {
        Destroy(gameObject);
    }
    ```
