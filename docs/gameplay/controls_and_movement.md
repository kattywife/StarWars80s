# Управление и перемещение (Controls & Movement)

Система управления джедаем спроектирована по гибридной схеме, вдохновленной аркадными шутерами с двумя стиками (Twin-stick shooters), где перемещение персонажа и ориентация его оружия независимы друг от друга.

---

## 1. Концепция и Смысл гибридного управления

Разделение движения и вращения решает ключевую задачу геймдизайна проекта «Стар80рс»: **одновременное маневрирование и активная оборона**.
*   **Свобода маневрирования:** Игрок может отступать назад или смещаться вбок (стрейфиться) с помощью клавиш WASD, при этом продолжая удерживать световой меч лицом к стреляющему штурмовику.
*   **Ощущение веса (Инерция):** Персонаж не разгоняется мгновенно. Плавный набор скорости и скольжение при торможении заставляют игрока планировать траектории движения, избегая заносов в толпу врагов.
*   **Рывок (Dash) как сейв-механика:** Рывок используется не только для ускорения, но и как тактический инструмент преодоления лазерных заграждений благодаря временной неуязвимости.

---

## 2. Визуальное оформление и Аудио

*   **Визуальный отклик разгона:** При достижении максимальной скорости движения за персонажем тянется легкий неоновый шлейф.
*   **Визуал рывка:** При активации рывка спрайт игрока получает прозрачность `0.4f` (эффект «размытия» скорости/неуязвимости), а световой меч оставляет за собой четкий шлейф через компонент `TrailRenderer` (`saberTrail`).
*   **Аудио:** Звуковые щелчки при активации рывка (если применимо к звуковым ассетам проекта).

---

## 3. Техническая реализация (Код)

Все расчеты движения выполняются в скрипте `JediController.cs` внутри физического цикла `FixedUpdate`, чтобы исключить зависимость скорости от частоты кадров (FPS).

### 3.1. Физический разгон и торможение (WASD)
Вместо мгновенного изменения вектора скорости, перемещение рассчитывается с использованием кривой разгона и метода линейной интерполяции `Vector2.MoveTowards`.

*   **Алгоритм обработки ввода:**
    1.  Направление считывается в `Update` и записывается в вектор `movement`.
    2.  В `FixedUpdate` ввод нормализуется: `Vector2 inputDir = movement.normalized`. Это гарантирует, что скорость джедая при движении по диагонали не превышает скорость по прямой.
    3.  Если зафиксирован новый ввод, таймер `moveInputTimer` увеличивается. Если игрок резко меняет направление на противоположное (угол вектора `< 0.3f`), таймер сбрасывается для имитации инерционного разворота.
    4.  Множитель скорости рассчитывается через оценку прогресса на кривой:
        ```csharp
        float progress = Mathf.Clamp01(moveInputTimer / moveAccelerationDuration);
        float speedMultiplier = moveAccelerationCurve.Evaluate(progress);
        ```
    5.  Рассчитывается целевая скорость с учетом замедления при получении урона (`currentSpeedMultiplier`):
        ```csharp
        Vector2 targetVelocity = inputDir * (maxMoveSpeed * currentSpeedMultiplier) * speedMultiplier;
        ```
    6.  Скорость плавно интерполируется от текущей к целевой:
        ```csharp
        activeMoveVelocity = Vector2.MoveTowards(activeMoveVelocity, targetVelocity, (maxMoveSpeed / moveAccelerationDuration) * Time.fixedDeltaTime);
        ```

### 3.2. Дублирующая система вращения (Rotation)
Вращение персонажа и меча может осуществляться двумя взаимоисключающими способами. Приоритет ввода распределяется динамически.

#### А. Вращение стрелками (Клавиатура)
Если игрок удерживает `LeftArrow` или `RightArrow`, рассчитывается угловое ускорение по кривой `arrowAccelerationCurve`. Максимальная скорость вращения составляет `360` градусов в секунду. Изменение угла применяется через:
```csharp
rb.MoveRotation(rb.rotation + arrowCurrentSpeed * Time.deltaTime);
```

#### Б. Вращение мышью (Приоритет действия)
Если игрок сдвигает мышь более чем на `1` пиксель от последней записанной позиции, управление вращением перехватывается мышью. 
1.  Позиция курсора переводится в мировые координаты.
2.  Рассчитывается угол направления `targetAngle`.
3.  Применяется сглаживание угловой скорости с помощью `Mathf.SmoothDampAngle` для исключения резких дерганий меча:
    ```csharp
    float targetAngle = Mathf.Atan2(lookDir.y, lookDir.x) * Mathf.Rad2Deg - 90f;
    float smoothedAngle = Mathf.SmoothDampAngle(rb.rotation, targetAngle, ref mouseRotationVelocity, mouseSmoothTime);
    rb.MoveRotation(smoothedAngle);
    ```

### 3.3. Механика рывка (Dash)
Рывок активируется по нажатию клавиши `dashKey` (по умолчанию `LeftShift`).

*   **Корутина `PerformDash()`:**
    1.  Запоминается направление рывка. Если джедай стоял на месте, рывок совершается вперед (направление `transform.up`), если двигался — в сторону зажатых клавиш WASD (`movement.normalized`).
    2.  Включается флаг неуязвимости `isDashing = true` (свойство `IsInvincible` возвращает `true`).
    3.  Устанавливается кулдаун: `lastDashTime = Time.time`.
    4.  Рассчитывается скорость рывка: `calculatedDashSpeed = dashDistance / dashDuration` (по умолчанию `4f / 0.18f`).
    5.  В цикле `while` джедай перемещается вперед:
        ```csharp
        rb.MovePosition(rb.position + dashDirection * calculatedDashSpeed * Time.deltaTime);
        ```
    6.  По истечении `dashDuration` (0.18с) возвращается исходная прозрачность спрайта, отключается шлейф, и флаг `isDashing` снимается.
