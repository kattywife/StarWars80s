# Механика отражения лазеров (Deflect Mechanic)

Механика отражения (Deflect) — центральный оборонительно-атакующий элемент геймплея «Стар80рс». Она позволяет игроку защищаться от вражеского огня и одновременно использовать снаряды штурмовиков против них самих.

---

## 1. Концепция и Смысл механики отражения

Идея отражения выстрелов решает несколько важных геймдизайнерских задач:
*   **Активная оборона:** Вместо обычного уклонения или блокирования урона, игрок должен активно подставлять меч под летящие снаряды.
*   **Осознанный риск:** Поскольку враги стреляют часто, а стандартный штурмовик имеет большой разброс, игроку необходимо позиционировать меч так, чтобы поймать летящую пулю, рискуя пропустить её в тело.
*   **Удовлетворение от игры (Game Feel):** Успешное отражение подкрепляется целой цепочкой аудиовизуальных эффектов сочности (Juice), создающих ощущение высокой кинетичности и мощи светового меча.

---

## 2. Визуальное оформление и Аудио

В момент соприкосновения пули с мечом запускается цепочка визуальных событий:
*   **Цветовая индикация:** Цвет снаряда мгновенно меняется с красного (опасен для игрока) на ярко-зеленый (опасен для врагов), наглядно показывая смену владельца пули.
*   **Вспышка искр:** В точке непосредственного контакта пули и меча спавнятся искры `DeflectSparkEffect.prefab`.
*   **Тряска экрана:** Камера совершает быстрое затухающее колебание.
*   **Заморозка времени:** На долю секунды вся симуляция игры замирает, фиксируя момент успешного парирования.

---

## 3. Техническая реализация (Код)

Логика отражения полностью обрабатывается внутри скрипта лазерного снаряда `BlasterBolt.cs` при взаимодействии с коллайдером светового меча `Lightsaber.cs`.

### 3.1. Детекция контакта (`OnTriggerEnter2D`)
Снаряд отслеживает столкновения через физический триггер:
```csharp
void OnTriggerEnter2D(Collider2D hitInfo)
{
    // ...
    else if (hitInfo.CompareTag("Lightsaber") && !isDeflected)
    {
        Deflect(hitInfo.transform, hitInfo);
    }
    // ...
}
```

### 3.2. Алгоритм отражения (`Deflect`)
При вызове метода `Deflect` происходят следующие шаги:

1.  **Маркировка снаряда:**
    Флаг `isDeflected` устанавливается в `true`, а спрайт перекрашивается в зеленый цвет:
    ```csharp
    isDeflected = true;
    spriteRenderer.color = Color.green;
    ```
2.  **Физическая отдача джедая назад (Knockback):**
    Пуля толкает джедая в направлении, противоположном направлению светового меча (вектор `-saberTransform.up`):
    ```csharp
    JediController jedi = saberTransform.GetComponentInParent<JediController>();
    if (jedi != null)
    {
        Vector2 pushDirection = -saberTransform.up;
        jedi.ApplyKnockback(pushDirection, knockbackStrength); // knockbackStrength = 8f
    }
    ```
3.  **Расчет точки контакта для спавна искр:**
    Искры должны появиться точно в месте соприкосновения. Для этого рассчитывается ближайшая точка на границах (Bounds) коллайдера меча к текущей позиции пули:
    ```csharp
    if (deflectSparkPrefab != null && saberCollider != null)
    {
        Vector3 contactPoint = saberCollider.bounds.ClosestPoint(transform.position);
        Instantiate(deflectSparkPrefab, contactPoint, Quaternion.identity);
    }
    ```
4.  **Микро-стоп времени (Time Freeze):**
    Вызывается заморозка времени на `0.04` секунды (40 миллисекунд) через `TimeFreeze.cs`:
    ```csharp
    TimeFreeze.Instance.Freeze(freezeDuration);
    ```
5.  **Тряска камеры:**
    Камера встряхивается на `0.1` сек с силой `0.15f` через `CameraFollow.Instance.Shake()`:
    ```csharp
    CameraFollow.Instance.Shake(shakeDuration, shakeMagnitude);
    ```
6.  **Изменение траектории пули:**
    Снаряд перенаправляется строго перпендикулярно лезвию меча (вектор `saberTransform.right`). При этом его скорость увеличивается в 1.5 раза для придания динамики отраженному удару:
    ```csharp
    rb.linearVelocity = saberTransform.right * (speed * 1.5f);
    transform.up = saberTransform.right; // Разворачиваем спрайт пули по направлению движения
    ```

### 3.3. Нанесение урона штурмовикам
После успешного отражения пуля при столкновении с объектом с тегом `Enemy` вызывает у него метод получения урона и уничтожается:
```csharp
else if (hitInfo.CompareTag("Enemy") && isDeflected)
{
    hitInfo.SendMessage("TakeDamage", SendMessageOptions.DontRequireReceiver);
    Destroy(gameObject);
}
```
