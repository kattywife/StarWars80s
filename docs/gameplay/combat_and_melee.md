# Боевая система и ближний бой (Combat & Melee)

В то время как отражение лазеров является основным средством дистанционной борьбы, круговая атака ближнего боя (Spin Attack) служит инструментом зачистки пространства вокруг игрока в экстренных ситуациях.

---

## 1. Концепция и Смысл ближнего боя

Ближний бой в игре «Стар80рс» дополняет оборонительный геймплей и решает следующие геймдизайнерские задачи:
*   **Оружие последнего шанса:** Если штурмовики подошли слишком близко или окружили джедая, одиночное отражение лазера не спасет. Круговая атака позволяет мгновенно зачистить радиус вокруг себя.
*   **Тактический риск:** Во время проведения круговой атаки (`isAttacking = true`) игрок временно теряет контроль над направлением меча — он не может целенаправленно отражать пули в конкретных врагов.
*   **Зонирование (Crowd Control):** Радиус выноса светового меча создает зону безопасности, физически расчищая пространство.

---

## 2. Визуальное оформление и Аудио

*   **Шлейф атаки:** При взмахе светового меча активируется неоновый шлейф через компонент `TrailRenderer` (`saberTrail`), визуализирующий круговую траекторию движения лезвия.
*   **Эффект плазмы (Мигание):** Для придания атаке агрессивности и яркости запускается корутина `FlashSaber()`. Она с высокой скоростью (интервал `0.05` сек) переключает цвет лезвия между его стандартным неоновым цветом и ослепительно белым (`Color.white`).
*   **Уничтожение врагов:** Успешный удар сопровождается анимацией взрыва штурмовика и воспроизведением звука `stormtrooper-death.mp3`.

---

## 3. Техническая реализация (Код)

Боевая система ближнего боя разделена между основным контроллером игрока `JediController.cs` и скриптом на дочернем объекте меча `Lightsaber.cs`.

### 3.1. Позиционирование и радиус атаки (`OnValidate`)
Меч является дочерним объектом по отношению к джедаю. Чтобы радиус атаки (вынос лезвия вперед) настраивался прямо в инспекторе, используется переопределение метода `OnValidate` (который срабатывает при изменении значений в редакторе Unity):
```csharp
private void OnValidate()
{
    if (lightsaberObject != null)
    {
        // Выносим меч по локальной оси X на величину saberDistance (по умолчанию 2f)
        lightsaberObject.transform.localPosition = new Vector3(saberDistance, 0f, 0f);
    }
}
```

### 3.2. Корутина круговой атаки (`PerformSpinAttack`)
Атака активируется при нажатии клавиши `E` и запускает физический разворот джедая на 360 градусов.

1.  **Блокировка управления:** Включается флаг атаки `isAttacking = true` (блокирует обычный WASD-разгон и вращение от мыши) и флаг нанесения урона мечом `isSpinning = true`.
2.  **Запуск визуальных эффектов:** Включается излучение шлейфа `saberTrail.emitting = true` и запускается мерцание меча `StartCoroutine(FlashSaber())`.
3.  **Интерполяция вращения:** 
    В цикле `while` считывается текущее время. Угол поворота тела игрока плавно интерполируется от исходного `startAngle` до конечного `targetAngle` (старт + 360) за фиксированное время `attackDuration = 0.35f`:
    ```csharp
    float startAngle = rb.rotation;
    float targetAngle = startAngle + spinDegrees;
    float elapsed = 0f;

    while (elapsed < attackDuration)
    {
        elapsed += Time.deltaTime;
        float progress = elapsed / attackDuration;
        
        float currentAngle = Mathf.Lerp(startAngle, targetAngle, progress);
        rb.rotation = currentAngle; // Применяем угол к Rigidbody2D
        
        yield return null;
    }
    rb.rotation = targetAngle; // Гарантируем точный финальный угол
    ```
4.  **Сброс флагов:** По окончании вращения управление возвращается игроку, шлейф отключается, флаги деактивируются.

### 3.3. Логика хитбокса и нанесение урона (`Lightsaber.cs`)
На дочернем объекте меча висит коллайдер в режиме триггера `Trigger` и скрипт `Lightsaber.cs`.

*   **Двойное отслеживание столкновений:**
    Чтобы урон регистрировался как в момент первого касания мечом врага (`OnTriggerEnter2D`), так и если враг сам наткнулся на уже вращающееся лезвие (`OnTriggerStay2D`), используются оба физических колбека:
    ```csharp
    void OnTriggerEnter2D(Collider2D other) { TryDamageEnemy(other); }
    void OnTriggerStay2D(Collider2D other)  { TryDamageEnemy(other); }
    ```
*   **Условие нанесения урона:**
    Меч наносит урон только в том случае, если джедай находится в активной фазе круговой атаки (`isSpinning == true`):
    ```csharp
    private void TryDamageEnemy(Collider2D other)
    {
        if (other.CompareTag("Enemy"))
        {
            // Наносим урон только если джедай сейчас крутится в атаке
            if (jedi != null && jedi.isSpinning)
            {
                other.gameObject.SendMessage("TakeDamage", SendMessageOptions.DontRequireReceiver);
                Debug.Log("Враг получил урон от светового меча!");
            }
        }
    }
    ```
