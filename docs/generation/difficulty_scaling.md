# Масштабирование сложности по уровням (Difficulty Scaling)

В игре «Стар80рс» сложность нарастает прогрессивно от 1 до 15 уровня. Это достигается за счет динамического изменения геометрических параметров карты в генераторе `GridLevelGenerator.cs` и поэтапного разблокирования новых геймплейных механик и врагов в `GameManager.cs`.

---

## 1. Концепция и Смысл прогрессии сложности

Прогрессия сложности разработана с целью удержания игрока в состоянии «потока» (Flow State):
*   **Уровни 1–4 (Обучение и адаптация):** Небольшие карты с малым числом комнат. Спавнятся только обычные и редкие элитные штурмовики. Игрок осваивает гибридный ввод и механику отражения.
*   **Уровень 5 (Угроза преследования):** Пробуждается Космический Червь (`wormUnlockLevel = 5`). Геймплей резко ускоряется, у игрока пропадает возможность подолгу задерживаться на одном месте.
*   **Уровень 7 (Квестовая точка):** На карте появляется Секретная Дискета. Игрок должен исследовать комнаты более тщательно, а не просто бежать к финишу.
*   **Уровни 10–14 (Вызов зачистки):** Плотность врагов максимальна. Появляется возможность получить Медный Ключ за полную зачистку уровня, что мотивирует игрока вступать в открытый бой со всеми штурмовиками вместо бегства.
*   **Уровень 15 (Финал):** Огромная карта-лабиринт с максимальным числом комнат и патрулей, в конце которой игрока ждет Золотое Яйцо (при условии сбора 3-х ключей).

---

## 2. Визуальное оформление и Аудио

*   **Органическая перегрузка экрана:** На поздних уровнях из-за высокой плотности штурмовиков экран заполняется десятками пересекающихся лазерных снарядов, создавая эффект динамичного Bullet Hell.
*   **Аудио-фон:** Постоянный фоновый гул выстрелов `stormtrooper-shoot.mp3` и регулярный рык Червя нагнетают напряжение на поздних этапах.

---

## 3. Техническая реализация (Код)

Масштабирование геометрии уровня рассчитывается математическими формулами в методе `Generate(int level)` скрипта `GridLevelGenerator.cs`.

### 3.1. Математические формулы масштабирования карты

Размеры карты и количество комнат масштабируются линейно, но ограничены сверху жесткими лимитами (Cap) для предотвращения падения производительности:

```text
Параметр               Формула                                  Минимум (Lvl 1)    Максимум (Lvl 15)
───────────────────────────────────────────────────────────────────────────────────────────────────────────
Количество комнат      TargetRoomCount = Mathf.Min(4 + level, 12)     5 комнат           12 комнат
Ширина карты (тайлы)   MapWidth = Mathf.Min(40 + (level * 3), 85)     43 тайла           85 тайлов
Высота карты (тайлы)   MapHeight = Mathf.Min(40 + (level * 3), 85)    43 тайла           85 тайлов
```

*Благодаря этим формулам площадь лабиринта на 15-м уровне увеличивается почти в 4 раза по сравнению с 1-м уровнем (с 1849 до 7225 тайлов).*

### 3.2. Органическое масштабирование плотности врагов
В генераторе `GridLevelGenerator.cs` нет прямой формулы множителя количества врагов от уровня. Однако их общее число растет органически и пропорционально площади карты по двум осям:

1.  **Комнатные враги:**
    Количество промежуточных комнат рассчитывается как `TargetRoomCount - 2` (первая комната игрока и последняя комната финиша не содержат врагов). С ростом уровня увеличивается число комнат (с 3 до 10), в каждой из которых гарантированно спавнится стража:
    *   В комнатах с кристаллами: от 4 до 5 штурмовиков.
    *   В комнатах без кристаллов: от 1 до 2 штурмовиков.
2.  **Коридорные патрули:**
    Количество патрульных штурмовиков в коридорах жестко привязано к площади пробитых ходов (2% от всех тайлов `TILE_CORRIDOR`):
    ```csharp
    int patrolCount = Mathf.RoundToInt(corridorTiles.Count * 0.02f);
    ```
    Так как на поздних уровнях комнат больше, коридоры становятся длиннее и разветвленнее, что автоматически увеличивает количество патрульных штурмовиков на карте.

### 3.3. Разблокирование механик по уровням (Ключевые пороги)

Скрипты ядра и генератора считывают переменную `currentLevel` для активации событий:

*   **Уровень 5 — Спавн Червя:**
    Генератор проверяет уровень перед планированием спавна червя:
    ```csharp
    if (currentLevelLoaded >= wormUnlockLevel && wormPrefab != null)
    {
        float roll = Random.Range(0f, 100f);
        if (roll <= wormSpawnChance) // Шанс спавна = 30%
        {
            Invoke("SpawnSpaceWorm", wormSpawnDelay); // wormSpawnDelay = 8f секунд
        }
    }
    ```
*   **Уровень 7 — Хрустальный ключ:**
    Логика размещения секретной дискеты в `GridLevelGenerator.cs`:
    ```csharp
    if (currentLevelLoaded == 7 && GameManager.Instance != null && !GameManager.Instance.hasCrystalKey)
    {
        // Спавн дискеты в случайной промежуточной комнате
    }
    ```
*   **Уровень 10+ — Медный ключ:**
    Логика активации проверки зачистки всех врагов в `GameManager.cs`:
    ```csharp
    if (currentLevel >= 10 && !hasCopperKey)
    {
        // Если убит последний враг на сцене, выдать Ключ №1
    }
    ```
