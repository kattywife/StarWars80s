# Правила размещения сущностей в комнатах

Размещение врагов, лута и препятствий привязано к комнатам и коридорам на основе волнового анализа Дийкстры.

---

## 1. Распределение по комнатам

*   **Комната 0 (Старт):** Абсолютно безопасная зона. Спавнится только джедай.
*   **Комната Финиша:** Содержит Портал OASIS. На 15-м уровне при истинной победе портал окрашивается в золотой цвет.
*   **Квестовые комнаты:** В одной из промежуточных комнат (на 7 уровне) спавнится Дискета.
*   **Комнаты охраны:** Промежуточные комнаты заселяются штурмовиками. Наличие кристалла Силы превращает комнату в укрепленный блокпост (4-6 охранников вместо 1-3).

---

## 2. Коридорные патрули

Штурмовики патрулируют не только комнаты, но и соединяющие их коридоры:
*   Плитки коридоров `DungeonTile.Corridor` сканируются.
*   На основе площади коридоров вычисляется количество патрулей (2% площади).
*   Патрульные перемещаются вдоль коридоров, устраивая засады джедаю между комнатами.


## 1. Логическая цепочка прохождения (Critical Path)

Карта Дийкстры предотвращает критические ошибки спавна: ключ от запертой зоны никогда не появится за силовым полем, а выход из симуляции всегда будет находиться в самом глубоком и опасном конце пещеры.

```text
[ Старт: Джедай ] (D = 0)
       │
       ▼ (Свободная зона, сбор кристаллов)
[ Поиск Ключа Доступа ] (D_key < D_gate) ──► Находится в тупике (Dead-End)
       │
       ▼
[ Силовой Щит (Gate) ] (Блокирует критический путь к финишу)
       │
       ▼
[ Портал OASIS (Exit) ] (D = Max) ──► Конец уровня

---

## 2. Визуальное оформление и Аудио

*   **Визуальные маркеры целей:** Игрок видит неоновые кристаллы, ретро-дискету на 7-м уровне или флаг финиша, выделяющиеся на фоне серых плит пола.
*   **Звуковые эффекты:** Появление Космического Червя всегда сопровождается паническим рыком `sandworm_roar.mp3`.

---

## 3. Техническая реализация (Код)

Заселение карты реализовано в методе `SpawnEntities()` скрипта `GridLevelGenerator.cs` и использует геометрические данные комнат `RoomData` и тайловой сетки `Tilemap`.

### 3.1. Спавн Джедая и Финиша в крайних точках
Поскольку комнаты в списке `rooms` хранятся в порядке их создания (от первой к последней), спавн игрока и выхода жестко привязан к краям массива:

1.  **Джедай (Игрок):** Спавнится строго в центре `rooms[0]`. Координаты переводятся из ячеек сетки в мировые физические координаты через `floorTilemap.GetCellCenterWorld()`:
    ```csharp
    Vector3 playerPos = floorTilemap.GetCellCenterWorld(new Vector3Int(rooms[0].center.x, rooms[0].center.y, 0));
    playerReference.transform.position = playerPos;
    ```
2.  **Финишная точка:** Спавнится в центре последней комнаты `rooms[rooms.Count - 1]`. При истинной победе на 15-м уровне префаб финиша видоизменяется:
    ```csharp
    GameObject finish = Instantiate(finishPrefab, finishPos, Quaternion.identity);
    if (currentLevelLoaded == 15 && GameManager.Instance.IsTrueVictory())
    {
        SpriteRenderer sr = finish.GetComponent<SpriteRenderer>();
        if (sr != null) sr.color = new Color(1, 0.84f, 0); // Золотой цвет
        finish.transform.localScale *= 1.5f; // Увеличение масштаба
    }
    ```

### 3.2. Комнатная стража и Кристаллы (Промежуточные комнаты)
Комнаты с индексами от `1` до `rooms.Count - 2` заселяются по следующему алгоритму:
1.  **Проверка генерации кристалла:** С вероятностью `crystalSpawnChance = 0.3f` в центре комнаты спавнится кристалл.
2.  **Расчет плотности охраны:**
    *   Если кристалл заспавнен: `guardCount` выбирается случайно в диапазоне `[4, 5]`.
    *   Если кристалла нет: `guardCount` выбирается случайно в диапазоне `[1, 2]`.
3.  **Выбор позиций и типов штурмовиков:**
    Позиции для каждого штурмовика выбираются случайно в пределах внутренней области пола комнаты (`GetRandomFloorInRoom`). С вероятностью 30% спавнится опасный `eliteStormtrooperPrefab`, в остальных 70% случаев — стандартный `stormtrooperPrefab`.

### 3.3. Патрулирование коридоров (`SpawnCorridorPatrols`)
Патрульные штурмовики спавнятся непосредственно в проходах.

1.  Генератор сканирует сетку и собирает координаты всех ячеек, помеченных как `TILE_CORRIDOR` в массив `corridorTiles`.
2.  Рассчитывается количество патрулей как 2% от общей площади коридоров:
    ```csharp
    int patrolCount = Mathf.RoundToInt(corridorTiles.Count * 0.02f);
    ```
3.  В цикле случайно выбирается индекс из списка свободных коридорных тайлов, туда спавнится штурмовик, а сам тайл удаляется из списка во избежание наложения врагов друг на друга.

### 3.4. Радиальный спавн Червя (`SpawnSpaceWorm`)
Если уровень `>= 5`, запускается шанс спавна Червя. Метод `SpawnSpaceWorm` рассчитывает спавн по полярным координатам на безопасном отдалении в `25f` единиц вокруг текущей позиции игрока:

```csharp
float angle = Random.Range(0, 360) * Mathf.Deg2Rad; // Случайный угол в радианах
Vector3 playerPos = playerReference.transform.position;

// Находим точку на окружности радиуса 25 единиц вокруг джедая
Vector3 spawnPos = playerPos + new Vector3(Mathf.Cos(angle), Mathf.Sin(angle), 0f) * 25f;

GameObject worm = Instantiate(wormPrefab, spawnPos, Quaternion.identity);
```

### 3.5. Секретная Дискета на уровне 7
Если текущий уровень равен `7` и у игрока еще нет Хрустального ключа, генератор выбирает случайную промежуточную комнату и спавнит в ее центре `diskettePrefab`:
```csharp
int disketteRoomIndex = Random.Range(1, rooms.Count - 1);
Vector3 diskettePos = floorTilemap.GetCellCenterWorld(new Vector3Int(rooms[disketteRoomIndex].center.x, rooms[disketteRoomIndex].center.y, 0));
Instantiate(diskettePrefab, diskettePos, Quaternion.identity);
```
