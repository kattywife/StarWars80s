# Жизненный цикл и состояния игры (Game Flow)

В игре «Стар80рс» реализован линейно-циклический игровой процесс, разделенный на фазы: запуск, вступительное повествование, цикличное прохождение уровней (с 1 по 15), переходы между уровнями и финальный исход (победа или поражение). Все эти переходы координируются через глобальные менеджеры.

---

## 1. Концепция и Смысл игровых фаз

Проект вдохновлен эстетикой аркадных автоматов и виртуальным пространством OASIS, поэтому структура игровых состояний повторяет классические аркады:
*   **Экран рекордов в Главном меню:** Демонстрация лучшего результата игрока для мотивации к новой сессии.
*   **Вступительное интро (Intro Crawl):** Погружение в лор в стиле «Звездных войн», настраивающее на атмосферу ретро-фантастики.
*   **Загрузочные экраны переходов (Transitions):** Использование экранов загрузки не только для подготовки сцены, но и как источника геймплейных подсказок и юмора той эпохи (с помощью Commodore 64 эстетики).
*   **Пауза и масштабирование времени (`Time.timeScale`):** Замораживание симуляции физики во время отображения UI для предотвращения случайной гибели игрока в меню.

---

## 2. Связующее визуальное и звуковое оформление

*   **Интро-титры (`IntroCrawl.cs`):** Медленно ползущий вверх по экрану текст под углом (или по вертикали), имитирующий кинематографическое вступление. Игрок может пропустить его нажатием `Space` или кликом мыши.
*   **Эффект печатной машинки (`TypewriterEffect.cs`):** Текст подсказок на экране переходов и причин смерти на экране поражения не появляется мгновенно, а последовательно «печатается», имитируя работу ретро-терминалов.
*   **Звуковые акценты переходов:** 
    *   Переход на новый уровень: победный марш `win.mp3`.
    *   Гибель игрока: грустная тема `game_over.mp3` и `jedi-death.mp3`.

---

## 3. Техническая реализация (Код)

Игровой цикл управляется посредством смены активных UI-панелей и вызовов методов генератора в `GridLevelGenerator.cs`.

### 3.1. Последовательность игрового цикла (Игровая петля)

Ниже представлена пошаговая техническая схема работы игрового цикла:

```text
[ Запуск игры ]
       │
       ▼
 1. Показ MainMenuPanel (Восстановление рекордов из PlayerPrefs)
       │
       ▼  (Игрок нажимает "СТАРТ")
 2. Вызов MenuController.StartGameBtn()
       ├─ Сброс статов через GameManager.PrepareNewGame()
       ├─ Скрытие всех панелей
       └─ Активация IntroPanel (Запуск ползущих титров IntroCrawl.cs)
       │
       ▼  (Окончание титров или Скип через Space/Клик)
 3. Вызов GameManager.StartLevel()
       ├─ Time.timeScale = 1 (Возобновление времени)
       ├─ Восстановление здоровья (health = 3)
       ├─ Скрытие всех UI-панелей
       ├─ Генерация карты через GridLevelGenerator.Generate(currentLevel)
       ├─ Показ обучающего туториала (TutorialManager.cs)
       └─ Обновление HUD (UIManager.cs)
       │
       ├───────────────────────── РЕЗУЛЬТАТЫ УРОВНЯ ─────────────────────────┐
       │                                                                     │
       ▼ (Игрок коснулся FinishPoint)                                        ▼ (Здоровье джедая <= 0)
 4а. Вызов GameManager.LevelCompleted()                                4б. Вызов GameManager.GameOver()
       ├─ Time.timeScale = 0 (Пауза физики)                                  ├─ Сохранение рекорда
       ├─ Сохранение рекорда                                                 ├─ Воспроизведение gameOverSound
       │                                                                     └─ Запуск GameOverRoutine (задержка 2 сек)
       ├─── [УРОВЕНЬ < 15]                                                   │
       │     └─ currentLevel++                                               ▼
       │     └─ Показ TransitionPanel (Генерация шутки/подсказки)      5б. Показ GameOverPanel
       │     └─ (Игрок жмет "Дальше" -> Переход на шаг 3)                    ├─ Вывод причины смерти через Typewriter
       │                                                                     ├─ Кнопка "Заново" -> На шаг 3 (уровень 1)
       └─── [УРОВЕНЬ == 15]                                                  └─ Кнопка "Меню" -> На шаг 1
             └─ Проверка IsTrueVictory()
             ├─ ДА -> VictoryPanel ("Пасхалка найдена", 3/3 ключей)
             └─ НЕТ -> VictoryPanel ("Протокол завершен", без ключей)
```

### 3.2. Компоненты управления потоком

#### А. Вступительные титры (`IntroCrawl.cs`)
Скрипт управляет вертикальным перемещением компонента `RectTransform` текстового блока. Он работает независимо от масштаба времени, используя `Time.unscaledDeltaTime`.

```csharp
void Update()
{
    timer += Time.unscaledDeltaTime;

    // Плавное движение текста вверх
    textTransform.anchoredPosition += Vector2.up * scrollSpeed * Time.unscaledDeltaTime;

    // Скип по нажатию Space или ЛКМ (с задержкой в 1 секунду для защиты от случайного клика)
    if (timer > canSkipTime && !isSkipping)
    {
        if (Input.GetKeyDown(KeyCode.Space) || Input.GetMouseButtonDown(0)) 
            SkipIntro();
    }

    // Автоматическое завершение при выходе текста за пределы экрана
    if (textTransform.anchoredPosition.y > exitPositionY && !isSkipping)
    {
        SkipIntro();
    }
}
```

#### Б. Панель перехода (`TransitionPanel.cs`)
При переходе на новый уровень панель генерирует текстовое сообщение. Если уровень имеет критическое значение для сюжета или геймплея, выводится жестко зафиксированная подсказка. В остальных случаях выбирается случайная шутка/хинт из `JokeManager`.

```csharp
public void Setup(int nextLevel)
{
    if (jokeManager == null) return;

    string finalString = "";

    // Ключевые точки обучения и предупреждений
    if (nextLevel == 2)
        finalString = "ПОДСКАЗКА: Отражай красные пули мечом, чтобы они стали зелеными и смертельными для врагов!";
    else if (nextLevel == 5)
        finalString = "ВНИМАНИЕ: На этом уровне пробуждается Космический Червь. Он проходит сквозь стены!";
    else if (nextLevel == 10)
        finalString = "СОВЕТ: Используй силу (Пробел) не только для убийства врагов, но и чтобы отпугнуть Червя.";
    else
        finalString = jokeManager.GetAnything(); // Случайная ретро-шутка или подсказка

    // Запуск эффекта последовательной печати текста
    typewriter.StartTyping(finalString);
}
```

#### В. Панель окончания игры (`GameOverPanel.cs`)
Принимает причину гибели игрока (строка, передаваемая из источника урона — пули штурмовика, укуса червя или падения) и уровень, до которого дошел игрок.

```csharp
public void Setup(string reason, int level)
{
    if (levelReachedText != null)
    {
        levelReachedText.text = "Вы достигли уровня: " + level;
    }

    if (reasonText != null)
    {
        if (typewriter == null) 
            typewriter = reasonText.GetComponent<TypewriterEffect>();

        // Эффект печати текста для большей атмосферности терминала смерти
        if (typewriter != null)
            typewriter.StartTyping("Причина: " + reason);
        else
            reasonText.text = "Причина: " + reason;
    }
}
```

## 💡 Особенности отладки переходов

Для тестирования переходов и балансировки в коде `LevelGenerator` ранее была заложена отладочная клавиша (закомментирована или убрана из финальной логики), а в `GridLevelGenerator.cs` добавлено контекстное меню `[ContextMenu("Generate Full Level")]`. Это позволяет запускать полную регенерацию карты прямо из инспектора Unity во время режима Play Mode без необходимости проходить игру с первого уровня.
