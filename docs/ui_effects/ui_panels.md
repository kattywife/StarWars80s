# Панели интерфейса и посимвольная печать текста (UI Panels & Typewriter)

Интерфейс (UI) игры «Стар80рс» выполнен в минималистичном стиле аркадных автоматов и компьютерных терминалов 80-х годов. Все экраны скомпонованы в виде независимых панелей, переключаемых центральным контроллером.

---

## 1. Концепция и Смысл панелей интерфейса

Графический интерфейс решает важные геймплейные и атмосферные задачи:
*   **Эстетика Commodore 64 / MS-DOS:** Текстовые блоки не появляются на экране мгновенно. Они «печатаются» символ за символом, воссоздавая ощущение взаимодействия с классическим ретро-компьютером.
*   **Компактный HUD (Heads-Up Display):** Во время игры на экране отображается только жизненно важная информация: здоровье (сердца), кристаллы Силы, индикаторы собранных ключей и текущий уровень. Это не перегружает зрение игрока и оставляет максимум пространства для боя.
*   **Игровой юмор и подсказки:** Экран перехода между уровнями выполняет функцию интерактивного загрузочного экрана, на котором транслируются ретро-шутки разработчиков и полезные хинты.

---

## 2. Визуальное оформление и Аудио

*   **Пиксельные шрифты:** Для всех текстовых блоков используются ретро-шрифты (8-битные гарнитуры), отрисовываемые через компонент `TextMesh Pro`.
*   **Анимация HUD:** При получении урона сердца на экране мгновенно заменяются на пустые контуры, давая четкий визуальный фидбек.
*   **Ретро-загрузка:** Экран переходов использует темный фон и зеленый/желтый текст, имитируя терминал командной строки.

---

## 3. Technical/Code breakdown (Техническая реализация)

Работа панелей опирается на синглтон `MenuController.cs`, который включает и выключает соответствующие игровые объекты (GameObjects), и скрипты конкретных панелей.

### 3.1. Панель Главного Меню (`MainMenuPanel.cs`)
При активации меню считывает из локального реестра `PlayerPrefs` максимальный рекорд и выводит его на экран:
```csharp
void OnEnable()
{
    // Считываем рекорд, если записи нет — выводим 0
    int record = PlayerPrefs.GetInt("Record", 0);
    recordText.text = "РЕКОРД: " + record + " УРОВНЕЙ";
}
```

### 3.2. Панель Смерти (`GameOverPanel.cs`)
Панель принимает причину гибели игрока и достигнутый уровень. Строка причины выводится через печатный эффект:
```csharp
public void Setup(string reason, int level)
{
    if (levelReachedText != null)
        levelReachedText.text = "Вы достигли уровня: " + level;

    if (reasonText != null)
    {
        if (typewriter == null) 
            typewriter = reasonText.GetComponent<TypewriterEffect>();

        if (typewriter != null)
            typewriter.StartTyping("Причина: " + reason); // Посимвольный вывод
        else
            reasonText.text = "Причина: " + reason;
    }
}
```

### 3.3. Панель Переходов (`TransitionPanel.cs`)
Формирует контекстные подсказки для ключевых этапов или выводит случайный текст:
*   Уровень 2 (подсказка по механике дефлекта).
*   Уровень 5 (предупреждение о Космическом Черве).
*   Уровень 10 (совет по защите Силой).
*   Остальные уровни (случайный анекдот или хинт из `JokeManager.cs`).
*   Выбранный текст передается на компонент `TypewriterEffect` для анимации.

### 3.4. Эффект печатной машинки (`TypewriterEffect.cs`)
Последовательная печать текста реализована через корутину, работающую независимо от масштаба времени. Это критично, так как во время отображения панелей игра стоит на паузе (`Time.timeScale = 0`).

*   **Корутина посимвольного вывода (`TypeRoutine`):**
    ```csharp
    private IEnumerator TypeRoutine(string fullText)
    {
        textMesh.text = ""; // Очищаем поле перед началом печати
        
        foreach (char letter in fullText.ToCharArray())
        {
            textMesh.text += letter; // Добавляем по одной букве
            
            // Если символ является знаком препинания, делаем паузу длиннее (для естественности чтения)
            if (letter == '.' || letter == '!' || letter == '?')
                yield return new WaitForSecondsRealtime(typingSpeed * 3); // typingSpeed = 0.05f
            else
                yield return new WaitForSecondsRealtime(typingSpeed);
        }

        typingCoroutine = null;
    }
    ```
*   **Метод мгновенного пропуска (`Skip`):**
    Если игрок не хочет ждать окончания печати, повторный клик или действие мгновенно раскрывает весь текст на экране, прерывая корутину:
    ```csharp
    public void Skip(string fullText)
    {
        StopAllCoroutines();
        textMesh.text = fullText;
        typingCoroutine = null;
    }
    ```
