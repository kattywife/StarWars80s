# Руководство по стилю (Visual Style Guide)

Визуальный стиль игры «Стар80рс» вдохновлен золотой эрой аркадных автоматов 1980-х годов, эстетикой киберпанка, синтвейва (Synthwave) и описанием виртуальной реальности OASIS из романа «Первому игроку приготовиться».

---

## 1. Ключевые столпы стиля

### 1.1. Ретро-футуризм и Неоновая палитра
Игра использует контрастные, насыщенные неоновые цвета на фоне темного космического окружения. Основные цвета палитры:
*   **Кибер-зеленый (Зеленая плазма):** Используется для отраженных игроком лазеров, индикации безопасных/союзных элементов и успешных действий.
*   **Лазерный красный (Имперский красный):** Используется для вражеских снарядов, индикации урона, опасных зон и подсветки испуганного Космического Червя.
*   **Синтвейв-голубой:** Цвет кристаллов Силы, шлейфа светового меча и элементов HUD.
*   **Золотой (Пасхальный желтый):** Цвет Ключей Холлидея, Золотого Яйца и финального флага на 15-м уровне при истинной победе.

### 1.2. Эстетика ЭЛТ-мониторов (CRT Scanlines)
Визуальный стиль текста и интерфейса имитирует аналоговые дисплеи старых терминалов:
*   Использование пиксельных моноширинных шрифтов.
*   Мягкое свечение (Glow Power) вокруг текста и неонового лезвия светового меча (URP 2D Bloom).
*   Эффект дрожания аналогового сигнала (случайные перепады альфа-канала текста) для имитации помех VHS-кассеты.

## 2. Специфика рендеринга в Unity

Проект использует современный конвейер рендеринга **Universal Render Pipeline (URP 2D)**:
*   **Renderer2D.asset:** Обеспечивает качественное смешивание слоев спрайтов.
*   **Световые эффекты:** Световой меч и лазерные снаряды используют материалы с поддержкой свечения (Emission). В настройках `DefaultVolumeProfile.asset` активирован эффект **Bloom**, создающий неоновый ореол вокруг плазмы лазеров на темном фоне пола.
