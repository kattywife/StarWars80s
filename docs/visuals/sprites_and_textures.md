# Спрайты и Текстуры (Sprites & Textures Reference)

Графические ресурсы проекта организованы в папке `Assets/Sprites/` и разделены по функциональным категориям.

---

## 1. Игровые персонажи (`Assets/Sprites/characters/`)

*   `jedi.png` — Спрайт джедая (игрока). Выполнен в виде пиксель-арта, представляет собой фигуру в плаще с капюшоном. Оружие (световой меч) рендерится как отдельный дочерний объект.
*   `штурмовик1.png`, `штурмовик2.png`, `штурмовик3.png` — Семейство имперских штурмовиков. Каждый тип имеет уникальные пиксельные отличия (элементы брони, шлемы, оружие) для быстрой идентификации игроком во время динамичного боя.
*   `spaceWorm.png` — Сегментированный спрайт Космического Червя. Голова и тело ориентируются по вектору движения, создавая иллюзию извивающегося чудовища.
*   `r2d2.png` — Спрайт дроида-помощника, используемый в элементах интерфейса или как декоративный элемент.

---

## 2. Окружение и Тайлы (`Assets/Sprites/enviroments/`)

*   `Floor.png` — Текстура пола. Темная металлическая или каменная плита со швами, служащая контрастным фоном для ярких лазеров.
*   `wall.png`, `wallClear.png` — Текстуры стен. Прорисованные пиксельные блоки, используемые в палитре тайлов `Tilemap` для автоматической сборки лабиринтов.
*   `флаг.png` — Флаг финишной точки (`Finish.prefab`), указывающий игроку на выход из симуляции.

---

## 3. Предметы и Квесты (`Assets/Sprites/items/`)

*   `меч.png` — Спрайт светового меча. Является тонкой неоновой полосой с рукоятью, вращающейся вокруг джедая.
*   `key1.png`, `key2.png`, `key3.png` — Пиксельные изображения Медного, Нефритового и Хрустального ключей.
*   `golden_egg.png` — Изображение Золотого Яйца, главного артефакта OASIS.

---

## 4. Интерфейс (`Assets/Sprites/ui/`)

*   `heart.png` / `empty_heart.png` — Сердца HUD для индикации здоровья джедая.
*   `кристалл.png` / `пустой кристалл.png` — Пиксельные слоты кристаллов для отображения уровня накопления Силы (ульты).
*   `button.png` — Стандартный пиксельный задник для кликабельных кнопок интерфейса.

---

## 5. Системные примечания для художников (`Assets/Sprites/неочищено/`)

В папке `Assets/Sprites/неочищено/` хранятся исходные файлы ассетов:
*   Файлы с постфиксом `-Photoroom.png` — это спрайты, прошедшие автоматическую очистку заднего фона.
*   Исходные JPG-фотографии и концепты.
*   **Рекомендация:** При подготовке игры к финальному релизу (Production Build) все исходники из папки `неочищено/` должны быть удалены из проекта Unity, чтобы уменьшить размер итоговой сборки и избежать путаницы с чистовыми спрайтами.
