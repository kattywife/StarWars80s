# Семейство штурмовиков (Base, Standard, Elite, Super)

Штурмовики — основные боевые единицы имперской симуляции в игре. Они разделены на три класса, каждый из которых обладает уникальной логикой прицеливания, стрельбы и маневрирования.

---

## 1. Концепция и Смысл классов врагов

Игровой дизайн штурмовиков построен на классическом поп-культурном меме об «ужасной меткости имперских солдат», который здесь превращен в полноценную геймплейную механику:

*   **Обычный штурмовик (Standard):** Стреляет с большим разбросом. Это дает игроку шанс маневрировать, а также усложняет отражение пули обратно во врага, так как траектория выстрела непредсказуема.
*   **Элитный штурмовик (Elite):** Стреляет снайперски точно в джедая. Это опасный враг, но именно его выстрелы легче всего гарантированно отразить обратно и убить его же пулей.
*   **Супер-штурмовик (Super):** Динамический охранник. В отличие от стационарных турелей (каковыми являются обычные и элитные враги), супер-штурмовик патрулирует территорию, активно сближается с игроком при обнаружении и стреляет только по прямой линии видимости.

## 2. Визуальное оформление и Аудио

### 2.1. Визуальные ресурсы
*   **Спрайты:** 
    *   `штурмовик1.png` — стандартный штурмовик.
    *   `штурмовик2.png` — элитный штурмовик.
    *   `штурмовик3.png` — супер-штурмовик.
*   **Эффект смерти:** При уничтожении штурмовика на его месте создается префаб взрыва пикселей `deathEffectPrefab` (`EnemyDeathEffect.prefab`).

### 2.2. Звуковое сопровождение
*   Каждый выстрел штурмовика сопровождается классическим лазерным звуком `stormtrooper-shoot.mp3`.
*   При гибели штурмовика воспроизводится крик `stormtrooper-death.mp3`.

## 3. Техническая реализация (Код)

Архитектура противников построена на принципах объектно-ориентированного программирования с использованием наследования и полиморфизма. Базовый абстрактный класс `BaseStormtrooper.cs` определяет общие правила жизни, получения урона и таймингов стрельбы, а конкретные подклассы переопределяют поведение.

```text
       [ BaseStormtrooper ] (Абстрактный базовый класс)
               │
               ├───────────────────────┼───────────────────────┐
               ▼                       ▼                       ▼
      [ Stormtrooper ]       [ EliteStormtrooper ]   [ SuperStormtrooper ]
      (Стрельба с разбросом)   (Точечный прицел)       (Поиск по Raycast,
                                                        движение к игроку)
```

### 3.1. Базовый класс `BaseStormtrooper.cs`
Предоставляет базовую логику для всех типов штурмовиков.

*   **Тайминги стрельбы:**
    Интервал между выстрелами рассчитывается индивидуально для каждого штурмовика в случайном диапазоне с учетом множителя сложности:
    ```csharp
    protected virtual void SetNextFireTime()
    {
        float baseCooldown = Random.Range(minFireRate, maxFireRate);
        float actualCooldown = baseCooldown / fireRateMultiplier;
        nextFireTime = Time.time + actualCooldown;
    }
    ```
*   **Метод получения урона (`TakeDamage`):**
    У штурмовиков всего 1 единица здоровья, поэтому получение урона от ульты или отраженного лазера мгновенно уничтожает их, вызывая тряску камеры и проверяя условие зачистки уровня для получения Медного ключа:
    ```csharp
    public virtual void TakeDamage()
    {
        if (deathEffectPrefab != null) Instantiate(deathEffectPrefab, transform.position, Quaternion.identity);
        if (CameraFollow.Instance != null) CameraFollow.Instance.Shake(0.08f, 0.12f);
        if (AudioManager.Instance != null) AudioManager.Instance.PlaySFX(AudioManager.Instance.stormtrooperDeathSound);
        if (GameManager.Instance != null) GameManager.Instance.CheckEnemyCount();
        Destroy(gameObject);
    }
    ```

### 3.2. Стандартный штурмовик (`Stormtrooper.cs`)
Реализует стрельбу с угловым разбросом.

*   **Алгоритм стрельбы:**
    Рассчитывает угол направления на игрока, добавляет случайное значение в диапазоне `[-spreadAngle, spreadAngle]` (по умолчанию `spreadAngle = 40f`), поворачивает точку стрельбы `firePoint` и спавнит префаб лазера `BlasterBolt.prefab`.

### 3.3. Элитный штурмовик (`EliteStormtrooper.cs`)
Реализует снайперскую стрельбу.

*   **Алгоритм стрельбы:**
    Рассчитывает точный угол между `firePoint` и позицией джедая, мгновенно разворачивает точку стрельбы в направлении игрока без какого-либо разброса и совершает выстрел.

### 3.4. Супер-штурмовик (`SuperStormtrooper.cs`)
Обладает полноценным поисковым ИИ и физическим перемещением.

*   **Сканирование линии видимости (Raycasting):**
    Метод `CheckLineOfSight()` проверяет, видит ли штурмовик игрока:
    1.  Проверяется дистанция. Если она больше `visionRadius` (10 единиц), штурмовик теряет игрока из вида.
    2.  Если дистанция позволяет, пускается массив лучей `Physics2D.RaycastAll` от штурмовика к джедаю.
    3.  Лучи игнорируют триггеры и других штурмовиков.
    4.  Если на пути луча встречается объект с тегом `Wall` или `Perimeter`, цикл прерывается — штурмовик не видит игрока сквозь стену.
    5.  Если луч доходит до объекта с тегом `Player`, выставляется `canSeePlayer = true`.

*   **Перемещение (`FixedUpdate`):**
    Если игрок обнаружен (`canSeePlayer == true`), штурмовик рассчитывает вектор движения к игроку и перемещает свое тело с помощью `rb.MovePosition()` со скоростью `moveSpeed = 3f`. Он также разворачивает свой спрайт лицом к направлению бега.
*   **Стрельба:** Супер-штурмовик может вызывать метод `ExecuteShooting()` только в том случае, если флаг `canSeePlayer` активен.
