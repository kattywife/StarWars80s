# Космический Червь (SpaceWorm)

Космический Червь — это элитная сквозная угроза (босс-таймер), пробуждающаяся начиная с 5-го уровня сложности. Он игнорирует препятствия лабиринта и непрерывно преследует джедая, заставляя игрока постоянно находиться в движении.

---

## 1. Концепция и Смысл противника

Введение Космического Червя решает важные геймдизайнерские задачи:
*   **Динамический таймер уровня:** Червь не позволяет игроку зачищать комнаты в медленном темпе или «отсиживаться» за стенами. Его появление — это сигнал к немедленному продвижению к финишу.
*   **Игнорирование геометрии:** Лабиринт комнат и стен, генерируемый `GridLevelGenerator.cs`, служит защитой от штурмовиков. Червь ломает это правило, проходя сквозь любые препятствия, что лишает игрока безопасных зон.
*   **Механика страха и взаимодействия с Ультой:** Червь неуязвим для обычных атак светового меча и отраженных лазеров. Единственный способ справиться с ним или отогнать его — использовать накопленную ультимативную Силу.

## 2. Визуальное оформление и Аудио

### 2.1. Визуальные эффекты
*   **Спрайт:** `spaceWorm.png` (вытянутый сегментированный спрайт космического монстра).
*   **Ориентация:** Спрайт червя постоянно разворачивается в направлении своего движения с помощью выравнивания вектора `transform.right`.
*   **Эффект вспышки (Flash Effect):** При испуге (когда игрок активирует Силу рядом с ним) спрайт червя на `0.5` секунды окрашивается в ярко-красный цвет (`flashColor`), после чего восстанавливает исходную расцветку.

### 2.2. Звуковое сопровождение
*   В момент спавна червя на уровне раздается громкий предупреждающий рык из файла `sandworm_roar.mp3`, сигнализирующий игроку о начале фазы преследования.

## 3. Техническая реализация (Код)

Поведение монстра реализовано в скрипте `SpaceWorm.cs` и полагается на триггерные столкновения и событийную модель Unity.

### 3.1. Перемещение и алгоритм преследования (`Update`)
Червь имеет два режима поведения: преследование и бегство (отступление).

1.  **Режим преследования (`isRetreating == false`):**
    Червь рассчитывает направление к игроку по прямой линии и перемещается с высокой базовой скоростью `speed = 15f`:
    ```csharp
    direction = (player.position - transform.position).normalized;
    transform.position += (Vector3)direction * speed * Time.deltaTime;
    ```
2.  **Режим отступления (`isRetreating == true`):**
    Вектор движения меняется на противоположный (от игрока). Червь движется со скоростью `currentRetreatSpeed` в сторону краев карты. Как только дистанция между ним и джедаем превышает `40` единиц, объект уничтожается:
    ```csharp
    direction = (transform.position - player.position).normalized;
    transform.position += (Vector3)direction * currentRetreatSpeed * Time.deltaTime;
    if (Vector2.Distance(transform.position, player.position) > 40f) 
        Destroy(gameObject);
    ```

### 3.2. Взаимодействие с игроком (`OnTriggerEnter2D`)
Если червь касается коллайдера игрока в режиме преследования:
1.  Он наносит урон джедаю, вызывая метод `TakeDamage()` на его контроллере.
2.  Переходит в режим кратковременного отступления со сниженной скоростью (`currentRetreatSpeed = speed / 2f`), давая игроку шанс перегруппироваться и убежать.

### 3.3. Событийная реакция на Силу (`ScareAway`)
Червь подписывается на событие использования ультимативной способности игроком в `GameManager`:
```csharp
void Start()
{
    GameManager.OnUltimateUsed += ScareAway;
}
```
При активации ульты Червь пугается: переходит в режим быстрого бегства с повышенной скоростью (`currentRetreatSpeed = speed * 1.5f`), окрашивается в красный цвет и улетает за пределы карты, где деспавнится.

### 3.4. Получение урона и Квест на Нефритовый ключ (`TakeDamage`)
Если Червь оказывается в непосредственном радиусе поражения ульты Силы (метод `JediController.UseForce()`), на него отправляется прямое сообщение `"TakeDamage"`. 

В отличие от отпугивания, прямое попадание волны Силы полностью уничтожает Червя и закрывает вторую часть квеста Холлидея:
```csharp
public void TakeDamage()
{
    // Игрок получает Нефритовый ключ (Ключ №2)
    if (GameManager.Instance != null)
    {
        GameManager.Instance.CollectKey(2, "Нефритовый ключ (Победа над Червем)");
    }
    
    Destroy(gameObject); // Мгновенное уничтожение
}
```

## ⚠️ Памятка по оптимизации для разработчиков

**Освобождение памяти при уничтожении:**
Скрипт `SpaceWorm.cs` подписывается на статическое событие `GameManager.OnUltimateUsed`. В C# подписка на статические события класса, который живет дольше (синглтон GameManager живет всю игру), объектом с коротким жизненным циклом (червь уничтожается при вылете за карту или смерти) гарантированно создает **утечку памяти (Memory Leak)**, если не выполнить отписку. 

В коде червя эта проблема успешно предотвращена с помощью явного вызова отписки в методе `OnDestroy()`:
```csharp
void OnDestroy()
{
    GameManager.OnUltimateUsed -= ScareAway;
}
```
При внесении изменений в ИИ червя или добавлении аналогичных событий всегда следите за тем, чтобы подписка и отписка были симметричными.
