# Предметы и интерактивное окружение (Items & Environment)

Интерактивные элементы окружения и собираемые предметы формируют вспомогательные циклы обратной связи (накопление ультимативной силы, выполнение квестов на ключи, завершение уровня).

---

## 1. Концепция и Смысл элементов окружения

Каждый собираемый предмет или элемент лабиринта решает определенную задачу в дизайне игры:

*   **Статичные Кристаллы Силы (`Crystal.cs`):** Точки интереса, стимулирующие игрока отклоняться от кратчайшего пути к финишу ради накопления ультимативной способности.
*   **Отскакивающие Кристаллы (`BouncingCrystal.cs`):** Механика наказания. При получении урона джедай «выбивает» кристалл из себя. Чтобы усложнить мгновенный автоматический сбор, кристалл отлетает в сторону по законам физики и блокируется для подбора на доли секунды.
*   **Секретная Дискета (`SecretDiskette.cs`):** Отсылка к ретро-носителям информации. Спавнится только на 7 уровне, предоставляя игроку Хрустальный ключ Холлидея.
*   **Финишная точка (`FinishPoint.cs`):** Конечная цель лабиринта. На 15-м уровне при условии сбора всех ключей она видоизменяется, сигнализируя об Истинной Победе.
*   **Стены и Пол (Tilemaps):** Формируют структуру уровня. Использование системы тайлов Unity (`Tilemap`) позволяет отрисовывать сотни стен с высокой производительностью и бесшовными коллайдерами.

## 3. Техническая реализация (Код)

### 3.1. Статичные Кристаллы (`Crystal.cs`)
Простой триггер, который при вхождении игрока напрямую обращается к синглтону `GameManager` для увеличения счетчика и уничтожает себя:
```csharp
void OnTriggerEnter2D(Collider2D other)
{
    if (other.CompareTag("Player"))
    {
        GameManager.Instance.AddCrystal();
        Destroy(gameObject);
    }
}
```

### 3.2. Физика вылетающих кристаллов (`BouncingCrystal.cs`)
При получении джедаем урона, если у него были кристаллы, спавнится физический аналог кристалла. Его задача — отлететь от игрока и не дать собрать себя мгновенно.

*   **Алгоритм физического импульса (`Awake`):**
    Кристалл получает случайный угол вылета и импульс силы `throwForce = 6f` с линейным затуханием `linearDamping = 3.5f` для плавной остановки:
    ```csharp
    float randomAngle = Random.Range(0f, 360f) * Mathf.Deg2Rad;
    Vector2 throwDirection = new Vector2(Mathf.Cos(randomAngle), Mathf.Sin(randomAngle));
    rb.linearVelocity = throwDirection * throwForce;
    ```
*   **Временное игнорирование игрока (Корутина):**
    Чтобы летящий кристалл рикошетил от стен, но при этом игнорировал коллизию с джедаем на время вылета (иначе игрок подберет его в ту же миллисекунду), используется функция `Physics2D.IgnoreCollision`:
    ```csharp
    private IEnumerator EnablePickupAfterDelay(Collider2D playerCol)
    {
        // Временно блокируем столкновения с игроком (коллайдер работает как триггер для стен)
        yield return new WaitForSeconds(pickupDelay); // pickupDelay = 0.8f
        
        if (col != null && playerCol != null)
        {
            // Возвращаем коллайдер в исходное состояние — теперь игрок может его собрать
            Physics2D.IgnoreCollision(col, playerCol, false);
        }
    }
    ```

### 3.3. Секретная дискета (`SecretDiskette.cs`)
Работает аналогично кристаллу, но привязывает успешный сбор к Ключу №3 (Хрустальный ключ):
```csharp
void OnTriggerEnter2D(Collider2D other)
{
    if (other.CompareTag("Player"))
    {
        if (GameManager.Instance != null)
        {
            GameManager.Instance.CollectKey(3, "Хрустальный ключ (Секретная дискета)");
        }
        Destroy(gameObject);
    }
}
```

### 3.4. Точка перехода на следующий уровень (`FinishPoint.cs`)
Отслеживает соприкосновение с игроком. Попадание в триггер врагов или их лазерных снарядов строго игнорируется:
```csharp
void OnTriggerEnter2D(Collider2D other)
{
    if (other.CompareTag("Player"))
    {
        if (GameManager.Instance != null)
        {
            GameManager.Instance.LevelCompleted();
        }
    }
}
```
*Для визуальной отладки границ триггера в редакторе Unity используется переопределение метода `OnDrawGizmos`, рисующее красный проволочный куб:*
```csharp
void OnDrawGizmos()
{
    Gizmos.color = Color.red;
    BoxCollider2D collider = GetComponent<BoxCollider2D>();
    if (collider != null) Gizmos.DrawWireCube(transform.position, collider.size);
}
```

### 3.5. Окружение в системе тайлов (`GridLevelGenerator.cs`)
В новой версии генератора вместо разрозненных префабов стен используется система `Tilemap`.
*   Поля генератора `floorTilemap` и `wallTilemap` отрисовывают пол и стены на основе переданных `TileBase` объектов (`floorTile` и `wallTile`).
*   Стены имеют встроенный компонент `TilemapCollider2D` и настроены на статический физический слой `Wall`, от которого отскакивают лазеры штурмовиков.
