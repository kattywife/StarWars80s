# Истинная концовка и Золотое Яйцо (Golden Egg Ending)

Истинная концовка игры «Стар80рс» — это финальная награда для игроков, собравших все три ключа Холлидея. Она разблокирует скрытый финал на 15-м уровне, отсылая к получению полного контроля над виртуальной вселенной OASIS.

---

## 1. Концепция и Смысл истинной концовки

Разделение финала на обычный и истинный решает важные геймдизайнерские задачи:
*   **Реиграбельность и мотивация:** Игрок, просто пробежавший уровни до конца, получает стандартный экран победы, информирующий о том, что ключи не найдены. Это мотивирует пройти тренировочный протокол повторно, исследуя секреты.
*   **Сюжетная кульминация:** Истинный финал — это не просто надпись «Победа». Игрок буквально находит Золотое Яйцо Холлидея, становясь полноправным владельцем системы OASIS, что является логическим завершением концепции игры.

---

## 2. Визуальное оформление и Аудио

*   **Золотой финиш:** Если джедай заходит на 15-й уровень с собранными ключами, флаг финиша в последней комнате увеличивается в `1.5` раза и окрашивается в яркий золотой цвет. Это визуальное подтверждение того, что условия выполнены.
*   **Экран истинной победы:** Панель победы `VictoryPanel.cs` отображает крупный заголовок золотого цвета `<color=yellow>ПАСХАЛКА ХОЛЛИДЕЯ НАЙДЕНА!</color>` и делает видимым спрайт Золотого Яйца `goldenEggIcon` (`golden_egg.png`).
*   **Звуковое сопровождение:** Окончание протокола сопровождается триумфальной победной темой `win.mp3`.

---

## 3. Техническая реализация (Код)

Реализация финала распределена между тремя классами: проверкой условий в `GameManager.cs`, генерацией визуальных изменений в `GridLevelGenerator.cs` и рендерингом UI в `VictoryPanel.cs`.

### 3.1. Верификация ключей (`GameManager.cs`)
Для проверки успешного сбора всех пасхалок в `GameManager.cs` заложен метод `IsTrueVictory()`:
```csharp
public bool IsTrueVictory()
{
    // Возвращает true только в том случае, если собраны ВСЕ три ключа
    return hasCopperKey && hasJadeKey && hasCrystalKey;
}
```

При соприкосновении джедая с финишем на 15-м уровне метод `LevelCompleted()` оценивает условия победы:
```csharp
public void LevelCompleted()
{
    Time.timeScale = 0; // Останавливаем физику игры
    SaveMyRecord();

    // winLevel = 15
    if (currentLevel >= winLevel)
    {
        if (AudioManager.Instance != null) 
            AudioManager.Instance.PlaySFX(AudioManager.Instance.winSound);
        
        if (IsTrueVictory())
        {
            // Показываем истинную победу (собрано 3 ключа из 3)
            MenuController.Instance.ShowVictory(3, 3);
        }
        else
        {
            // Показываем стандартную победу без пасхалок (0 из 3)
            MenuController.Instance.ShowVictory(0, 3);
        }
    }
    else
    {
        currentLevel++;
        MenuController.Instance.ShowTransition(currentLevel);
    }
}
```

### 3.2. Изменение финиша на уровне 15 (`GridLevelGenerator.cs`)
При спавне объектов в методе `SpawnEntities()` генератор проверяет, является ли уровень финальным и собрал ли игрок все ключи. Если условия верны, префаб финиша масштабируется и перекрашивается:
```csharp
if (currentLevelLoaded == 15 && GameManager.Instance != null && GameManager.Instance.IsTrueVictory())
{
    SpriteRenderer sr = finish.GetComponent<SpriteRenderer>();
    if (sr != null) 
        sr.color = new Color(1, 0.84f, 0); // Придаем золотой цвет флагу
    
    finish.transform.localScale *= 1.5f; // Увеличиваем размер флага на 50%
}
```

### 3.3. Логика переключения UI-панели (`VictoryPanel.cs`)
Компонент `VictoryPanel` динамически настраивает текстовые блоки и иконку Яйца в зависимости от переданного количества собранных ключей:

```csharp
public void Setup(int collected, int total)
{
    // Если собраны все 3 ключа (collected == total)
    if (collected == total) 
    {
        titleText.text = "<color=yellow>ПАСХАЛКА ХОЛЛИДЕЯ НАЙДЕНА!</color>";
        statsText.text = "Вы прошли протокол OASIS и нашли Золотое Яйцо.\nТеперь вы владелец системы!";
        
        if (goldenEggIcon != null) 
            goldenEggIcon.SetActive(true); // Включаем иконку Золотого Яйца
    }
    else // Обычная победа
    {
        titleText.text = "ПРОТОКОЛ ЗАВЕРШЕН";
        statsText.text = $"Вы прошли все уровни, но не нашли ключи Холлидея.\nСобрано ключей: {collected} из {total}";
        
        if (goldenEggIcon != null) 
            goldenEggIcon.SetActive(false); // Скрываем иконку Золотого Яйца
    }
}
```
