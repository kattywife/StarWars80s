# Квестовая система: Ключи Холлидея (Keys System)

Поиск трех ключей Холлидея (Медного, Нефритового и Хрустального) — это глобальный второстепенный квест, отсылающий к сюжету «Первому игроку приготовиться». Сбор всех трех ключей необходим для открытия секретного финала на 15-м уровне.

---

## 1. Концепция и Смысл системы ключей

Квестовая система разработана для поощрения различных стилей игры и проверки всесторонних навыков игрока:
*   **Медный Ключ (Проверка боевого мастерства):** Выдается за полную зачистку всех врагов на уровне 10 или выше. Это стимулирует игрока не просто бежать к финишу, а вступать в опасные затяжные перестрелки.
*   **Нефритовый Ключ (Проверка тактического выживания):** Выдается за уничтожение Космического Червя. Игрок должен накопить 3 кристалла Силы и подпустить смертельно опасного Червя вплотную, чтобы нанести решающий удар ультой.
*   **Хрустальный Ключ (Проверка внимательности):** Спавнится в виде Секретной Дискеты в лабиринте 7-го уровня. Игрок должен тщательно исследовать комнаты, уклоняясь от врагов.

---

## 2. Визуальное оформление и Аудио

### 2.1. Визуальный отклик HUD
*   **Иконки ключей на экране:** В левой/правой части экрана постоянно отображаются три иконки ключей (`key1.png`, `key2.png`, `key3.png`).
*   **Индикация владения:** Если ключ не собран, его иконка затеняется и становится полупрозрачной (альфа-канал `0.2f`). В момент сбора прозрачность сбрасывается в `1f` (иконка горит белым цветом).
*   **Панель оповещения:** При сборе ключа сверху выдвигается туториал-панель `TutorialManager.cs` с золотым текстом `<color=yellow>КЛЮЧ ПОЛУЧЕН!</color>`.

### 2.2. Аудио
Каждый успешный сбор ключа подтверждается проигрыванием торжественного звука победы `win.mp3`.

## 3. Техническая реализация (Код)

Регистрация, хранение и верификация ключей происходят в `GameManager.cs`, а отрисовка состояния — в `UIManager.cs`.

### 3.1. Метод регистрации ключей (`CollectKey`)
Глобальный метод `CollectKey` принимает индекс ключа (1, 2 или 3) и его название, предотвращая повторную запись:

```csharp
public void CollectKey(int keyIndex, string keyName)
{
    if (keyIndex == 1 && !hasCopperKey) hasCopperKey = true;
    else if (keyIndex == 2 && !hasJadeKey) hasJadeKey = true;
    else if (keyIndex == 3 && !hasCrystalKey) hasCrystalKey = true;
    else return; // Ключ уже собран или передан неверный индекс

    // Обновление иконок на экране
    if (UIManager.Instance != null)
    {
        UIManager.Instance.UpdateKeys(hasCopperKey, hasJadeKey, hasCrystalKey);
    }

    // Выдвижная плашка оповещения
    if (TutorialManager.Instance != null)
        TutorialManager.Instance.ShowTutorial("<color=yellow>КЛЮЧ ПОЛУЧЕН!</color>\n" + keyName);
    
    // Эпичный звук победы
    if (AudioManager.Instance != null)
        AudioManager.Instance.PlaySFX(AudioManager.Instance.winSound);
}
```

### 3.2. Логика получения каждого ключа

#### А. Медный Ключ (Ключ №1 — Зачистка уровня 10+)
При смерти любого штурмовика вызывается метод `CheckEnemyCount()` в `GameManager`:
```csharp
public void CheckEnemyCount()
{
    if (currentLevel >= 10 && !hasCopperKey)
    {
        // Ищем всех активных врагов на сцене
        GameObject[] enemies = GameObject.FindGameObjectsWithTag("Enemy");
        
        // Если остался всего 1 враг (тот, который сейчас умирает и еще не удален в конце кадра)
        if (enemies.Length <= 1)
        {
            CollectKey(1, "Медный ключ (Зачистка 10+ уровня)");
        }
    }
}
```

#### Б. Нефритовый Ключ (Ключ №2 — Победа над Червем)
Когда Космический Червь (`SpaceWorm.cs`) попадает под удар волны Силы, вызывается его метод `TakeDamage()`, который напрямую обращается к `CollectKey`:
```csharp
public void TakeDamage()
{
    if (GameManager.Instance != null)
    {
        GameManager.Instance.CollectKey(2, "Нефритовый ключ (Победа над Червем)");
    }
    Destroy(gameObject);
}
```

#### В. Хрустальный Ключ (Ключ №3 — Секретная дискета)
Секретная Дискета спавнится только на 7 уровне. Скрипт `SecretDiskette.cs` отслеживает соприкосновение с джедаем через триггер:
```csharp
void OnTriggerEnter2D(Collider2D other)
{
    if (other.CompareTag("Player"))
    {
        if (GameManager.Instance != null)
        {
            GameManager.Instance.CollectKey(3, "Хрустальный ключ (Секретная дискета)");
        }
        Destroy(gameObject); // Уничтожение дискеты на сцене
    }
}
```

### 3.3. Обновление визуального состояния на HUD (`UIManager.cs`)
При изменении флагов владения `UIManager` корректирует цвет и прозрачность иконок:

```csharp
public void UpdateKeys(bool hasCopper, bool hasJade, bool hasCrystal)
{
    // Белый цвет при наличии (1,1,1,1), полупрозрачный серый при отсутствии (1,1,1,0.2)
    if (copperKeyUI != null) copperKeyUI.color = hasCopper ? Color.white : new Color(1, 1, 1, 0.2f);
    if (jadeKeyUI != null) jadeKeyUI.color = hasJade ? Color.white : new Color(1, 1, 1, 0.2f);
    if (crystalKeyUI != null) crystalKeyUI.color = hasCrystal ? Color.white : new Color(1, 1, 1, 0.2f);
}
```

## ⚠️ Важное архитектурное предупреждение для разработчиков

**Баг одновременной смерти врагов:**
Метод `CheckEnemyCount()` использует `GameObject.FindGameObjectsWithTag("Enemy")` для подсчета выживших врагов. Если несколько врагов умирают **одновременно в одном кадре** (например, от взрывной волны ульты), в момент проверки они оба еще существуют в сцене (так как `Destroy` срабатывает в конце кадра). 

В этом случае длина массива `enemies.Length` вернет `2` или больше, и проверка `enemies.Length <= 1` **провалится для обоих врагов**, из-за чего игрок зачистит уровень, но **не получит Медный Ключ**. Для исправления этого бага переведите учет количества врагов на счетчик живых юнитов внутри синглтона `GameManager`, как указано в общей архитектуре проекта.
